QUICK FIX COMMANDS - COPY VÀ PASTE VÀO TERMINAL
=================================================================

>> BƯỚC 1: Kiểm tra Docker đang chạy
docker ps

>> BƯỚC 2: Fix database trong Docker (CHẠY LỆNH NÀY!)
docker exec -it englishwebai_backend python force_recreate_table.py

>> BƯỚC 3: Restart container
docker restart englishwebai_backend

>> BƯỚC 4: Kiểm tra logs
docker logs englishwebai_backend --tail 20

=================================================================
ALL-IN-ONE (Chạy tất cả một lúc):
=================================================================

docker exec -it englishwebai_backend python force_recreate_table.py && docker restart englishwebai_backend && echo "DONE! Now test in browser."
